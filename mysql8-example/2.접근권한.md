## 1. 데이터베이스(Database) 관리

애플리케이션의 데이터를 저장할 공간인 데이터베이스를 생성하고 관리합니다.

### 1.1. 데이터베이스 생성
`financial_app`이라는 이름의 데이터베이스를 생성합니다. 이때, **문자셋은 `utf8mb4`로, 콜레이션은 `utf8mb4_unicode_ci`로 지정**하는 것을 강력히 권장합니다. 이모지(emoji)까지 포함하는 모든 문자를 문제없이 저장하고, 정확한 비교/정렬 규칙을 적용하기 위함입니다.

```sql
CREATE DATABASE financial_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 1.2. 데이터베이스 목록 확인

현재 MySQL 서버에 생성되어 있는 모든 데이터베이스의 목록을 확인합니다.

```sql
SHOW DATABASES;
```

### 1.3. 데이터베이스 상세 정보 확인

특정 데이터베이스(`financial_app`)의 문자셋과 콜레이션 설정이 올바르게 적용되었는지 다시 한번 상세하게 확인합니다.

```sql
SELECT SCHEMA_NAME, DEFAULT_CHARACTER_SET_NAME, DEFAULT_COLLATION_NAME
FROM information_schema.SCHEMATA WHERE SCHEMA_NAME = 'financial_app';
```

### 1.4. 데이터베이스 사용

현재 세션에서 기본으로 사용할 데이터베이스를 지정합니다. 이 명령어를 실행한 이후부터는 테이블 이름을 명시할 때 데이터베이스 이름을 생략할 수 있습니다.

```sql
USE financial_app;
```

## 2\. 사용자(User) 관리

데이터베이스에 접속할 사용자를 생성하고 관리합니다. 보안을 위해 애플리케이션별로 전용 사용자를 만드는 것이 좋습니다.

### 2.1. 사용자 생성

애플리케이션이 사용할 `app_user`를 생성합니다. 접속 위치에 따라 사용자를 구분할 수 있습니다.

  * **`'app_user'@'localhost'`**: MySQL 서버와 같은 장비(localhost)에서 접속하는 경우에만 허용됩니다.
  * **`'app_user'@'%'`**: 원격지(다른 서버)에서의 접속을 모두 허용합니다. `%`는 모든 IP 주소를 의미합니다.


```sql
-- 로컬 접속용 사용자 생성
CREATE USER 'app_user'@'localhost' IDENTIFIED BY 'secure_password';

-- 원격 접속용 사용자 생성
CREATE USER 'app_user'@'%' IDENTIFIED BY 'secure_password';
```

> **보안 Tip**: 실제 운영 환경에서는 `%` 대신 애플리케이션 서버의 특정 IP 주소를 지정하는 것이 더 안전합니다.

### 2.2. 사용자 목록 확인

현재 MySQL에 등록된 모든 사용자와 해당 사용자가 접속할 수 있도록 허용된 호스트(Host) 정보를 확인합니다.

```sql
SELECT User, Host FROM mysql.user;
```

## 3\. 권한(Privilege) 관리

생성된 사용자에게 특정 데이터베이스에 대한 작업 권한을 부여하고 관리합니다. **최소 권한의 원칙(Principle of Least Privilege)** 에 따라 꼭 필요한 권한만 부여하는 것이 중요합니다.

### 3.1. 사용자 권한 부여

`app_user`가 원격(`%`)으로 접속했을 때 `financial_app` 데이터베이스의 **모든 테이블(`*`)** 에 대해 기본적인 데이터 조작(CRUD) 권한인 **`SELECT`, `INSERT`, `UPDATE`, `DELETE`를 부여**합니다.

```sql
GRANT SELECT, INSERT, UPDATE, DELETE ON financial_app.* TO 'app_user'@'%';
```

  * `DROP`, `CREATE`, `ALTER` 등과 같은 DDL(데이터 정의어) 권한은 부여하지 않아 애플리케이션이 실수로 테이블 구조를 변경하는 것을 방지할 수 있습니다.

### 3.2. 부여된 권한 확인

특정 사용자가 어떤 권한을 가지고 있는지 확인합니다. 권한을 부여한 후 확인하는 습관은 실수를 줄여줍니다.

```sql
SHOW GRANTS FOR 'app_user'@'%';
```

### 3.3. 권한 적용

`GRANT`와 같은 권한 관리 명령어를 실행한 후, 변경된 권한 내용을 메모리에 즉시 반영하기 위해 실행합니다.

```sql
FLUSH PRIVILEGES;
```

**참고**: 최신 MySQL 버전에서는 `GRANT`, `REVOKE`, `CREATE USER` 등의 명령어가 실행되면 자동으로 권한이 갱신되어 `FLUSH PRIVILEGES`를 생략해도 되는 경우가 많습니다. 하지만 명시적으로 실행해주는 것이 안전하며, 특히 `mysql` 데이터베이스의 grant 테이블을 직접 수정한 경우에는 반드시 필요합니다.
