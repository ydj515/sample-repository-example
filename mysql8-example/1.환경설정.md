## 1\. 문자셋(Character Set) 및 콜레이션(Collation) 확인

데이터베이스에 텍스트를 올바르게 저장하고 비교하기 위한 기본 설정을 확인합니다. 특히 한글과 같은 다국어 환경에서 매우 중요합니다.

### 1.1. 서버의 Character Set 관련 변수 확인

클라이언트, 데이터베이스, 서버 간의 데이터가 어떤 문자셋으로 인코딩되어 통신하고 저장되는지 전반적인 설정을 확인합니다. `utf8mb4`가 권장됩니다.

```sql
SHOW VARIABLES LIKE 'character_set%';
```

  * **`character_set_client`**: 클라이언트가 서버로 보내는 SQL 문의 문자셋
  * **`character_set_connection`**: 서버가 받은 SQL 문을 처리할 때 사용하는 문자셋
  * **`character_set_database`**: 기본 데이터베이스의 문자셋
  * **`character_set_results`**: 쿼리 결과를 클라이언트로 보낼 때의 문자셋
  * **`character_set_server`**: 서버의 기본 문자셋

### 1.2. 서버의 Collation 관련 변수 확인

Collation은 특정 문자셋 내에서 문자를 정렬하고 비교하는 규칙을 정의합니다. `utf8mb4_general_ci` 또는 `utf8mb4_unicode_ci`가 일반적으로 사용됩니다.

```sql
SHOW VARIABLES LIKE 'collation%';
```

  * **`collation_connection`**: 연결 시 문자열 비교에 사용되는 콜레이션
  * **`collation_database`**: 기본 데이터베이스의 콜레이션
  * **`collation_server`**: 서버의 기본 콜레이션

## 2\. 성능 관련 주요 변수 확인

데이터베이스 성능에 직접적인 영향을 미치는 핵심 메모리 설정과 연결 수 제한을 확인합니다.

### 2.1. InnoDB 버퍼 풀 크기 (`innodb_buffer_pool_size`)

데이터와 인덱스를 메모리에 캐싱하는 공간입니다. 디스크 I/O를 줄여 성능을 크게 향상시키므로 가장 중요한 설정 중 하나입니다.

```sql
SHOW VARIABLES LIKE 'innodb_buffer_pool_size';
```

  * **Value**: 바이트(Byte) 단위로 표시됩니다. 일반적으로 DB 전용 서버의 경우 전체 물리 메모리의 50% \~ 70%로 설정하는 것을 권장합니다.

### 2.2. 최대 연결 수 (`max_connections`)

MySQL 서버에 동시에 접속할 수 있는 클라이언트의 최대 수를 제한합니다.

```sql
SHOW VARIABLES LIKE 'max_connections';
```

  * **Value**: 애플리케이션의 커넥션 풀(Connection Pool) 설정과 서버의 가용 메모리를 고려하여 적절한 값으로 설정해야 합니다. 너무 높게 설정하면 메모리 부족을 유발할 수 있습니다.

## 3\. 서버 현재 상태(Status) 확인

서버의 실시간 상태를 모니터링하여 부하 정도나 안정성을 파악합니다.

### 3.1. 현재 연결된 클라이언트 수

현재 MySQL 서버에 접속해 있는 클라이언트(Thread)의 수를 보여줍니다.

```sql
SHOW STATUS LIKE 'Threads_connected';
```

  * 이 수치가 `max_connections`에 근접하면 새로운 연결 요청이 실패할 수 있으므로 모니터링이 필요합니다.

### 3.2. 서버 가동 시간

서버가 마지막으로 시작된 후부터 현재까지 경과된 시간을 초 단위로 보여줍니다.

```sql
SHOW STATUS LIKE 'Uptime';
```

  * 장애 발생 후 재시작 여부나 서버가 얼마나 오랫동안 안정적으로 운영되었는지 확인할 수 있습니다.

## 4\. 메모리 사용량 확인

서버에 설정된 주요 메모리 버퍼의 크기를 메가바이트(MB) 단위로 환산하여 가독성 좋게 확인합니다.

```sql
SELECT
    (@@innodb_buffer_pool_size / 1024 / 1024) AS buffer_pool_mb,
    (@@key_buffer_size / 1024 / 1024) AS key_buffer_mb;
```

  * **`buffer_pool_mb`**: InnoDB 스토리지 엔진이 사용하는 캐시 메모리 크기입니다.
  * **`key_buffer_mb`**: MyISAM 스토리지 엔진의 인덱스 캐시 메모리 크기입니다. 최근에는 대부분 InnoDB를 사용하므로 `innodb_buffer_pool_size`가 더 중요합니다.

## 5\. 동적 설정 변경

MySQL 서버를 재시작하지 않고 일부 설정을 즉시 적용합니다. 단, `my.cnf`(또는 `my.ini`) 설정 파일에 반영하지 않으면 서버 재시작 시 초기화됩니다.

### 5.1. 최대 연결 수 조정

`max_connections` 값을 1000으로 즉시 변경합니다.

```sql
-- 연결 수 조정 (즉시 적용)
SET GLOBAL max_connections = 1000;

-- 설정 확인
SHOW VARIABLES LIKE 'max_connections';
```

### 5.2. InnoDB 버퍼 풀 크기 조정 (주의 필요)

InnoDB 버퍼 풀 크기를 4GB로 변경합니다. 이 설정은 서버에 큰 영향을 줄 수 있으며, 동적 변경이 지원되더라도 일반적으로는 설정 파일 수정 후 안전하게 재시작하는 것을 권장합니다.

```sql
-- InnoDB 설정 (재시작 필요 권장)
SET GLOBAL innodb_buffer_pool_size = 4294967296;  -- 4GB
```

## 6\. 타임존(Timezone) 설정 및 확인

데이터베이스의 시간 관련 데이터(TIMESTAMP 등)를 정확하게 처리하기 위해 타임존을 설정합니다.

### 6.1. 현재 타임존 확인

서버 전체에 적용되는 `global` 타임존과 현재 접속한 세션에만 적용되는 `session` 타임존을 확인합니다.

```sql
SELECT @@global.time_zone, @@session.time_zone;
```

### 6.2. 타임존 설정

글로벌 타임존을 한국 시간(KST, UTC+9)으로 설정합니다.

```sql
SET GLOBAL time_zone = '+09:00';
```

## 7\. 데이터베이스별 상세 정보 확인

서버 내 각 데이터베이스(스키마)의 기본 문자셋과 콜레이션 설정을 확인합니다.

```sql
SELECT
    SCHEMA_NAME,
    DEFAULT_CHARACTER_SET_NAME,
    DEFAULT_COLLATION_NAME
FROM information_schema.SCHEMATA;
```

## 8\. 슬로우 쿼리 로그(Slow Query Log) 설정

실행 시간이 오래 걸리는 쿼리를 찾아내어 성능을 개선하기 위해 슬로우 쿼리 로그를 활성화합니다.

### 8.1. 슬로우 쿼리 로그 활성화 및 시간 설정

슬로우 쿼리 로그 기능을 켜고, 2초 이상 실행되는 쿼리를 기록하도록 설정합니다.

```sql
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL long_query_time = 2; -- 2초 이상
```

### 8.2. 현재 로그 관련 설정 확인

슬로우 쿼리 로그를 포함한 서버의 모든 로그 관련 설정을 확인하여 로그 파일 경로(`slow_query_log_file`) 등을 파악할 수 있습니다.

```sql
SHOW VARIABLES LIKE '%log%';
```

이러한 명령어를 정기적으로 사용하고 모니터링하면 데이터베이스를 안정적이고 효율적으로 운영하는 데 큰 도움이 됩니다.
