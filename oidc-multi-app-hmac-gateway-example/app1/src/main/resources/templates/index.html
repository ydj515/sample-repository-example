OIDC Authorization + Internal HMAC

OIDC와 Gateway HMAC 흐름

로그인은 Keycloak OIDC로 처리하고, API 요청은 Gateway가 내부 HMAC 서명 헤더를 붙인 뒤 Backend가 다시 검증합니다.

1 Browser

로그인 요청을 시작하고 앱 세션 쿠키를 보관합니다.

2 App 1

OIDC client oidc-app1 로 authorization request를 보냅니다.

3 Keycloak

사용자 인증, role 매핑, authorization code 발급을 담당합니다.

4 Token / Claims

앱은 code를 token으로 교환하고 claims 기반 권한을 계산합니다.

5 Gateway HMAC

API Gateway가 외부 주입 헤더를 제거하고 X-Internal-Auth 서명을 붙입니다.

6 Backend API

Backend는 HMAC, session id, method, path를 검증한 뒤 API를 실행합니다.
